## tmp/ 残留 session protocol（项目级）

每次会话开始 `ls tmp/`，对每个残留文件三选一：

- **还在用**（当前对抗期内）→ 留着，告诉 Jack 是什么、为什么还要
- **对抗已收敛但 handoff 未落盘** → `mv` 到 `docs/handoff/` 并登记
- **已废弃 / handoff 已落盘** → `rm`（草稿无保留价值）

超过 14 天没动的 tmp 文件，**默认提示 Jack 是否删除**。
