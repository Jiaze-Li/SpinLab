```
Workflow Store：
  只承担 (1) 协调 ingestion/render/persistence (2) 暴露状态字段 (3) mutation 入口
  不含 (a) 业务规则提取 (b) 业务策略合并 (c) label 解析
```

#### AS-26：业务规则提取到 UseCase

当前 `AHEWorkspaceStore` 内的 `extractAHEMetricsPerSeries(...)` / `extractSingleSeriesMetrics(...)` 两个方法包含 Hc 拐点查找、R_AHE 中值估算、label 字符串解析（substrate alias / temperature 提取）三类业务规则。

**本轮策略：保持行为不变，把方法搬到 UseCase**。本轮**不**重构 input 形态——继续用 rendered `PlotSeries.label` 作为 metadata 来源（已是当前生产路径）。typed series metadata 重构留作后续观察项（见 Cross-Region Doubts For 5.1.14：「AHE metric extraction 从 rendered series label 读取 sampleKey」）。

新建 `UseCases/ExtractAHEMetricsUseCase.swift`：

```swift
struct ExtractAHEMetricsUseCase {
    struct Input {
        let series: [PlotSeries]                     // 临时输入：携带 rendered label
        let configuration: AHEMetricsConfiguration
        // TODO: 14a 评估替换为 typed metadata input
    }
    struct Output {
        let perSeries: [SeriesKey: AHEMetricsRecord]
        let warnings: [AHEExtractionWarning]
    }
    
    func execute(_ input: Input) -> Output { ... }
}

// 内部辅助：label 解析作为兼容路径，输出 typed components
private struct SeriesLabelComponents {
    let sampleKey: String?
    let substrateAlias: String?
    let temperatureK: Double?
    let unparsed: String?            // label 中无法解析的剩余部分
}

private func parseSeriesLabel(_ raw: String) -> SeriesLabelComponents { ... }
```

**warning 条件（必须明确）**：

- label 完全无法解析（无 sampleKey / substrate / temperature 任一字段） → `AHEExtractionWarning.labelUnparseable(raw: String)` 加入 warnings
- label 部分缺失（如 sampleKey 有但 temperature 缺） → `AHEExtractionWarning.labelPartial(raw: String, missing: [String])`
- 业务规则失败（Hc 拐点未找到 / R_AHE 数据点不足） → 各自专属 warning case

**fallback 行为**：

- label 解析失败时：sampleKey 退回 series.id；substrateAlias / temperature 退回 nil；不阻断整轮提取
- 缺失字段不写入 record（不发明默认值），下游消费方按需处理

`AHEWorkspaceStore.runAnalysis` 内：

```swift
let metricsUseCase = ExtractAHEMetricsUseCase()
let outcome = metricsUseCase.execute(.init(series: ..., configuration: ...))
self.lastExtractedMetrics = outcome.perSeries
self.extractionWarnings = outcome.warnings
```

#### AS-27 #2a：sorted 移到 Store 计算属性

`AHEWorkspaceView.AHEMetricOverridePanel.body` 当前：

```swift
ForEach(store.lastExtractedMetrics.values.sorted(by: ...), id: \.id) { ... }
```

**性质定调**：本排序是 **presentation projection**（用于 UI 展示稳定性 + 用户体验），**不是**业务优先级排序，不影响 metric persistence 顺序、不影响 apply-to-library 顺序。

**Sort key 定义**：

1. 主键：`sampleKey`（按字典序升序），保证同一样本的 record 聚集
2. 次键：`temperatureK ?? .greatestFiniteMagnitude`（缺温度的 record 排尾）
3. 末键：`record.id`（确保稳定排序，避免 SwiftUI ForEach 闪烁）

如未来发现排序影响保存或应用顺序（即 sort 实际是业务优先级而非展示投影），需重新评估并改由 UseCase Output 提供 `orderedRecords: [AHEMetricsRecord]`，本轮假设保持纯展示投影。

```swift
// in AHEWorkspaceStore
var sortedExtractedMetrics: [AHEMetricsRecord] {
    lastExtractedMetrics.values.sorted { lhs, rhs in
        if lhs.sampleKey != rhs.sampleKey { return lhs.sampleKey < rhs.sampleKey }
        let lt = lhs.temperatureK ?? .greatestFiniteMagnitude
        let rt = rhs.temperatureK ?? .greatestFiniteMagnitude
        if lt != rt { return lt < rt }
        return lhs.id < rhs.id
    }
}

// in View
ForEach(store.sortedExtractedMetrics, id: \.id) { ... }
```

#### AS-27 #2b：trim/Double + reason 归一化移到 Store mutating 方法

当前 View 内 `updateCandidate(value:reason:)`：

```swift
let trimmed = value.trimmingCharacters(in: .whitespaces)
let parsed = Double(trimmed)
```

```swift
func updateMetricCandidate(rawValue: String, rawReason: String, key: SeriesKey) {
    let trimmed = rawValue.trimmingCharacters(in: .whitespaces)
    let parsed = Double(trimmed)
    let finalReason = rawReason.isEmpty ? "manual override" : rawReason
    candidates[key] = AHEMetricCandidate(value: parsed, reason: finalReason)
}

// in View
store.updateMetricCandidate(rawValue: textInput, rawReason: reasonInput, key: row.key)
```

## 4. 风险预案

| 风险 | 表现 | 处置 |
|---|---|---|
| ExtractAHEMetricsUseCase fixture 复刻 baseline 困难 | 输出与修复前数值有 floating-point 微差 | 用相对误差容差 1e-9；如仍不过，先 grep `extractAHEMetricsPerSeries` 确认未跨过非确定性边界（如 Date / Random） |
| Store 字段变多（sortedExtractedMetrics 等计算属性）触发 SwiftUI 重渲染过多 | UI 卡顿 | 计算属性放在 `private(set) var` 缓存或 lazy 投影；如必要降级到 mutating 方法手动同步 |
| AS-30 的 legendIndexMap 改为字段后旧调用方未同步 | 图例索引错位 | grep `_snapshotRenderer` 所有 reference + 跑 PlotCanvas 渲染回归 |
| 新 UseCase 文件未登记 Code Map | pre-commit hook 卡 commit | 跑 commit 前手动确认 architecture/workbench/WORKFLOW_CONTRACTS.md 已加行；`scripts/install_git_hooks.sh --check` 验证 hook 存在 |
| AHE View 改 binding 后输入响应延迟 | 用户敲一个字 → store 更新 → SwiftUI re-render 耗时 | 维持 binding 形式（用 store.updateMetricCandidate 包装在 binding setter）；如确实卡，回头改 mutating 方法直调 |
