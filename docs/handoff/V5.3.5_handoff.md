# SpinLab 5.3.5 Handoff（对抗评审后融合方案）

> 阶段：执行中 | 入选规则来源：Claude 方案 + Codex 方案对抗评审 2026-04-26
> 设计思路与版本回顾归档时迁移到 docs/history/v5.3.5.md（按 workflow.md §7 闭环规则）。

## 设计要点（裁决后）

1. **隐藏点状态 per-tab**：放进 `TabRenderState`，不放 `TabRenderManager`
2. **Pack 持久化**：完全下沉 `tabStates` —— 不扩 `ThreeOmegaPackConfig` 顶层
3. **字号入 Pack 路径**：落代码前**必须先核对** `chartStyleOverrides` 当前是否真进 Pack；若否，补字段（任务 1 前置死任务）
4. **任务 4 启用条件**：payload-能力驱动 `hasPointLabels = payload.series.contains { !$0.pointLabels.isEmpty }`，不写死 workflow ID
5. **Copy PNG 2x fast path**：接受复用预渲染 `imageData`（`baseOptions.pixelScale` 是字面量 2.0，等值比较确定性）；1x/3x 按需重渲染
6. **菜单形态**：纯 `Copy PNG 1x / 2x / 3x` 三项，无 "(Default)" 后缀，无单按钮 fallback
7. **点命中冲突**：**首命中优先**（renderer 顺序）
8. **数据点 hit-test 优先级**：高于 legend / xLabel / yLabel / tick label，但仅当 `hasPointLabels` 为真时执行

## 接口契约（双方落代码必须对齐）

### A. 字号通道（任务 1）
- `WorkbenchChartStyle` 新字段：`pointLabelFontSize: CGFloat = 20`
- styleParams key：`"pointLabelFontSize"`
- `WorkbenchPlotCanvas.EditTarget` 新 case：`.pointLabel(seriesIndex: Int, pointIndex: Int)`
- `editFontSizeKey` 映射 `.pointLabel → "pointLabelFontSize"`
- `Self.fontSizeKeyPath(_:)` 静态映射加 `"pointLabelFontSize"`
- `WorkbenchChartRenderer` L256 `let labelFont: CGFloat = 20` → `let labelFont = style.pointLabelFontSize`

### B. 显隐 + Pack（任务 2/3）
- `TabRenderState` 加字段：`var hiddenPointLabelIndicesBySeries: [Int: [Int]] = [:]`（Pack 形态用 [Int: [Int]]）
- `TabRenderManager` 提供 helper：`func togglePointLabelVisibility(seriesIndex: Int, pointIndex: Int)` + `func hiddenPointLabelSet(for tab: Tab) -> [Int: Set<Int>]`
- `WorkbenchRenderPipeline.Input` 加字段：`hiddenPointLabelsBySeries: [Int: Set<Int>] = [:]`
- `WorkbenchChartRenderer.Options` 加字段：`hiddenPointLabelsBySeries: [Int: Set<Int>] = [:]`
- `WorkbenchChartRenderer` L240 收集 pendingLabels 时跳过 `hiddenPointLabelsBySeries[seriesIndex]?.contains(k) == true` 的 index（圆点仍画）
- `WorkbenchPlotLayout` 加字段：`pointDotHitTargets: [PointHitTarget]`，含 `seriesIndex / pointIndex / hitRect`（半径 7px = 圆点半径 3.5 + padding 3.5）
- `WorkbenchPlotCanvas.EditTarget` 新 case：`.pointDot(seriesIndex: Int, pointIndex: Int)` —— **不弹字号面板**，命中即调 `onTogglePointLabelVisibility?(s, p)` return
- `WorkbenchPlotCanvas` 新 prop：`onTogglePointLabelVisibility: ((Int, Int) -> Void)?`
- `handleTap` 顺序（首命中优先）：title → xLabel → yLabel → legend → **pointDot（如 hasPointLabels）→ pointLabel（如 hasPointLabels）** → tick → 取消

### C. Codable 兼容（任务 3）
- `TabRenderState` 必须显式实现 `init(from decoder:)`，对新字段缺失场景返回 `[:]`（合成 Codable 在缺 key 时的行为非确定，必须显式兜底）
- Pack 形态 `[Int: [Int]]` 在 JSONEncoder 默认行为下会把 Int key 字符串化（"0":[1,3]）—— 接受这点，decode 端透明还原

### D. Copy PNG shell（任务 5）
- `WorkbenchPlotCanvas` 新 prop：`onCopyPNG: ((CGFloat) -> Data?)?`
- `WorkbenchPlotCanvas` 新静态常量：`static let copyPNGScales: [CGFloat] = [1, 2, 3]`
- `WorkbenchRenderPipeline.Input` 加字段：`pixelScaleOverride: CGFloat? = nil`
- 各 store 新方法：`func renderPNGAtScale(_ scale: CGFloat) -> Data?`
  - **2x fast path**：`if scale == 2.0, let cached = activeImageData { return cached }`
  - 否则：`buildPipelineInput(payload:, baseOptions:.init(), pixelScaleOverride: scale)` → `WorkbenchRenderPipeline.render` → 返回 `output.imageData`
- `WorkflowWorkspaceShell` 装配：`onCopyPNG: { scale in store.renderPNGAtScale(scale) }`
- 菜单实现（Canvas 内）：
  ```swift
  .contextMenu {
      Menu("Copy PNG") {
          ForEach(Self.copyPNGScales, id: \.self) { s in
              Button("\(Int(s))x") {
                  guard let d = onCopyPNG?(s) else { return }
                  let pb = NSPasteboard.general
                  pb.clearContents()
                  pb.setData(d, forType: .png)
              }
          }
      }
  }
  ```

## 风险点 watchlist

- 任务 1.5 核对结果：若 `chartStyleOverrides` 不在 Pack 里，C1 commit 范围扩大（要补 Pack 字段或下沉到 TabRenderState 的 chartStyleOverridesByTab）
- 3x PNG 渲染同步阻塞 main thread ≈ 100-150ms，可接受；4x 以上加入时再考虑 async
- `Set<Int>` ↔ `[Int]` 在 TabRenderManager / TabRenderState 层的转换边界：运行态查命中用 Set，持久化用 sorted [Int]
- 点重叠时（理论上 plot 上不可能、但 multi-series 同坐标可能）首命中策略要在测试覆盖
