# v5.3.3 — Multi-Tab Render State Manager

**Date**: 2026-04-14

## Summary

Introduced `TabRenderManager<Tab>` as a workflow-agnostic shell-level capability for managing per-tab display state and render outputs. All three workflow stores (AHE, XY Rotation, 3ω) migrated to use this unified framework, replacing scattered dictionaries and individual fields.

## Motivation

Per-tab display overrides (legend position, title/axis label overrides, series label renames) and render outputs (PNG, layout, manifest payload) were independently managed by each workflow store using ad-hoc data structures. This caused:

1. 3ω: 7 individual `Data?` fields + 4 dictionaries for per-tab overrides
2. XY: 2 individual `Data?` fields + global overrides that didn't follow tab switches
3. Three bugs rooted in structural problems (overrides lost on batch re-render, legend hit rects out of sync, manifest cache overwritten by style re-renders)

## Architecture

### New types (Workbench/V3/TabRenderManager.swift)

- `TabRenderState` — per-tab display overrides (Codable for pack persistence)
- `TabRenderOutput` — per-tab render cache (imageData, layout, manifestPayload)
- `TabRenderManager<Tab>` — @Observable generic container owning active tab, shared settings, per-tab states and outputs
- `AHEWorkbenchTab` — single-case tab enum for uniform usage

### Key design decisions

- Shell manages tabs; workflow manages domain data. Clear separation.
- `buildPipelineInput()` bridges per-tab state + shared settings → `WorkbenchRenderPipeline.Input`
- Pack persistence via `snapshotStates()`/`restoreStates()` with string-keyed dictionaries
- WorkbenchPlottingStore protocol unchanged; stores add forwarding computed properties
- Style re-renders preserve existing manifestPayload (don't overwrite with nil)

## Files changed

- **New**: `TabRenderManager.swift`
- **Modified stores**: `AHEWorkspaceStore`, `XYRotationWorkspaceStore`, `ThreeOmegaWorkspaceStore`
- **Modified contracts**: `ThreeOmegaPackContracts`, `XYRotationPackContracts` (scattered per-tab dicts → `tabStates: [String: TabRenderState]`)
- **Modified views**: all three workspace views + `WorkbenchFeatureStore` interaction snapshot
- **CGPointCodable** moved from `ThreeOmegaPackContracts` to `TabRenderManager` (shared)

## Bugs fixed (structural)

- #1: 3ω batch re-render losing per-tab overrides — overrides now stored per-tab, read from correct tab on re-render
- #4: Legend hit rects not following overridden label widths — layout and label overrides come from same tab state
- #7: 3ω manifest cache expired after re-render — style re-renders preserve existing manifest payload
