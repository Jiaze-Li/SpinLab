# v5.3.2 — Plot Render Pipeline Unification

Date: 2026-04-14

## Summary

提取统一的 `WorkbenchRenderPipeline`，消除三 workflow 中重复的 6 步出图管线。

## Problem

5.3.1 后三条渲染路径（AHE inline / 3ω `_render()` / XY `_render()`）各自执行相同的 11 步序列。改管线需改三处。

## Solution

`WorkbenchRenderPipeline.render(Input) throws -> Output`：

1. 保存原始 axisMapping
2. 应用 styleParamsPatch
3. 应用 display overrides (title / axis labels)
4. 应用 seriesRenderMode
5. 合并 chartStyleOverrides
6. 解析 ChartStyle
7. resolvedOptions
8. 计算 layout（用原始 label）
9. 应用 seriesLabelOverrides
10. renderPNG
11. 恢复 manifest axisMapping

## Key design decisions

- Pipeline throws；3ω/XY 在 wrapper 中 `try?`，AHE 直接 `try`
- `manifestPayload.axisMapping` 由 pipeline 统一恢复，不再是 AHE 特殊处理
- `styleParamsPatch` 先于 `chartStyleOverrides` 应用，后者优先级更高
