# v5.3.1 — Plot Shell Capability Expansion

Date: 2026-04-14

## Summary

Workbench plot shell 通用能力扩展，覆盖渲染模式、字号/tick 密度配置、轴标题对齐修正、右键复制等。

## Changes

### Bug fixes
- Chart title 取消加粗（`titleBold` default false）
- X/Y axis title 对齐修正：居中于画板（plotRect）而非整个图像
- XY Rotation 默认 y title 固定为 `Rxx (Ω)` / `Rxy (Ω)`，移除 stacked/center 后缀
- AHE 渲染路径统一使用 `resolvedOptions`（与 3ω/XY 一致）

### New infrastructure
- `WorkbenchChartStyle` struct：统一 7 项样式参数（字号 ×4 + tick 密度 ×2 + titleBold），从 `styleParams` 解析
- `WorkbenchPlotLayout` 新增 `plotRect` + `rendererSize`，canvas 不再独立计算 padding
- `SeriesRenderMode` enum（line/scatter/lineAndScatter）替代 `isScatter: Bool`，自定义 Codable 兼容旧数据

### New features
- 绘图模式切换：Line / Scatter / Line+Scatter，通用控件三 workflow 统一
- 字号可调：title / axis / tick / legend 四项 font size picker
- Tick 密度可调：X / Y stepper
- 右键 Copy PNG：`.contextMenu` 写入 `NSPasteboard`
- XY x=180 辅助线：toggle 控制灰色虚线

### Architecture
- `WorkbenchPlottingStore` 协议扩展：`seriesRenderMode` + `chartStyleOverrides`
- 三 workflow 的 render path 统一走 ChartStyle → renderer → layout → canvas 链路
- 辅助线通过 `styleParams["auxVerticalX"]` 传递，renderer 通用绘制
