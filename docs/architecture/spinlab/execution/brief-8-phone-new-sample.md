# 任务 8：手机网页新建样品，电脑自动收进 Library

插在任务 1 之后做，因为任务 1（PR #194）已经把"新建样品"做成了一条路。本任务让手机也走这条路，并把新建窗口补全。
前置：任务 1（PR #194）已合并。做法已经定好，不需要单独的设计阶段。

## 目标

在实验室用手机填一张表，提交后样品出现在电脑的 SpinLab 里，字段和 Excel 导入的样品一致。

## 需求

1. 手机网页（`SpinLab-Web-Library`）有"新建样品"页，字段照我现在 Obsidian 的模板：
   - 日期：默认今天，可改。
   - 实验室：下拉，选项来自规则本。
   - 材料：下拉，选项来自规则本；衬底沿用电脑上的三个选项（处理方式默认 o、衬底类型、取向），也来自规则本。
   - 批次：填写批次号。样品名自动生成为"批次 - 衬底"，不用我另起名。
   - 温度、气压、样品高度：数字，单位自动补。
   - 能量：镜前能量、激光器电压、激光器输出能量三个数，外加"有无衰减镜"勾选框。
   - 脉冲：预打次数、生长次数、频率；频率不填按 2 Hz。
   - 用途、备注：纯文字。
   - RHEED：固定格子 Grid、Focus、X1、Y1、Y2、X2，选填，默认折叠。
2. 提交成功后页面明确显示"已提交"。失败显示"未提交"，已填内容保留在手机里，信号恢复后我点一次重新提交即可。不做自动后台重发。
3. 我提交一次，电脑上只出现一个样品。手机重发、电脑重复拉取都不会多出样品。
4. 电脑关机时提交的样品，开机打开 SpinLab 后能收进来（路线 B 为手动导入）。
5. 电脑上的"新建样品"窗口也有同样的字段，写出的数据格式和手机一致。
6. 三个入口（电脑直接建、Excel 导入、手机提交）对同一份数据产生同样的数值标签和单位。
7. 只有我本人能提交；别人打开链接不能写。
8. 样品详情页不再重复显示批次、衬底（已在 #194 做）。

## 不做

- 把样品写回 Excel。原因见"已定的做法"。
- 自动后台重发、离线队列。
- 在手机上浏览或编辑已有样品。
- 删除样品、给旧样品补数值标签。
- 把已经导入的旧样品的"能量"拆成三个。

## 代码现状（`T01` HEAD，Agent 开工前须自行复核）

- 数值标签的读取和单位补全在 `LibraryRegistryParser`，目前只由 Excel 导入使用；新建窗口没有数值标签输入，手动新建的样品没有数值标签。
- 规则本里的数值标签名为：厚度（预打、生长次数）、氧压、温度、电压、电阻、磁场、能量。没有实验室、样品高度、频率，也没有生长材料的选项列表。
- 能量的拆分与 2 Hz 默认值已有现成规则：`RegistryGrowthEnergyMapper`、`RegistryGrowthPulseMapper`。
- 已有"Obsidian 记录写入 Excel"的功能（`Registry/RegistryGrowth*`）：规划、预览、写入前确认、过期校验都有。
- 网页库是一个静态站加一个小型云端数据库，目前只存"样品备注"，没有登录相关代码；我记得网页已在邮箱登录保护之下，须在开工时核实。

## 硬边界（不可改）

- **不写回 Excel。** 写回后下次同步会把同一个样品再导入一次，电脑上会出现两个。要做，须先让原生样品记住它对应的 Excel 行，另开任务。
- **选项来自规则本。** 实验室、生长材料、衬底三项的选项只加进规则本，手机和电脑都读它，不在别处另写一份。
- **数值标签的换算和单位只留一处。** Excel 导入、电脑新建、手机提交共用，不各写一份。
- **同一次提交只产生一个样品**（骨架 K4），沿用任务 1 的做法：编号在打开表单时生成。
- **手机提交不能直接改 Library 文件。** 手机不碰电脑上的数据。

## 前提（Assumptions，请你确认或划掉）

- 只有我一个人使用；手机和电脑不会同时改同一个样品。
- 网页已在邮箱登录保护之下（我的记忆，须开工时核实）。
- 实验室手机有时没信号；断网时手动再点一次提交可以接受。
- 能量拆成三个数值标签只用于新建的样品，旧样品保持单个"能量"。

## 备选路线（开工前先比较，选最简单、最能复用的，写明为什么）

- **路线 A：云端待收。** 手机把提交内容存到网页库已有的云端数据库，SpinLab 启动或刷新时取走并建样品，成功后在云端标记已收。电脑关机也不丢；需要给电脑端一个取件凭证。
- **路线 B：手机只生成一段文字。** 手机页填完生成一份文本，我复制或分享到电脑，SpinLab 里一键导入。不需要云端写入和凭证；代价是多一步手动搬运，没有"自动出现"。
- Agent 可以提出路线 A、B 之外更简单的办法，但必须说明它怎么满足上面的硬边界和需求 3、4。

## 我怎么验收

1. 手机打开新建页，批次 PN200，材料 SRO，衬底 o STO(001)，其余字段随便填，提交。看到"已提交"。
2. 打开电脑上的 SpinLab。PN200 下出现这个样品，名字是"PN200 - o STO(001)"，数值标签齐全且带单位，频率显示 2 Hz。
3. 再点一次手机的提交（模拟重发），电脑上仍是一个样品。
4. 断开手机网络提交，页面显示"未提交"且内容还在；恢复网络再点提交，成功。
5. 电脑关闭时在手机提交，之后打开 SpinLab 样品自动出现。
6. 在电脑上用新建窗口填同样的内容，和手机提交的样品字段、格式一致；再导入一行同样内容的 Excel，三者的数值标签格式一致。
7. 用没登录的浏览器打开页面，不能提交。

Agent 另需用自动测试证明：同一编号重复收取只产生一个样品；收取失败不留半成品；旧样品读取不变。
